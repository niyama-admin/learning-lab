# Theme Index

Each theme is an independently reusable consulting module with a shared structure:

- **Outcome**: the business or engineering result the theme supports.
- **Scope**: capabilities and decisions included in the theme.
- **Core deliverables**: reusable artifacts produced during an engagement.
- **Measures**: evidence that the capability is working.
- **Guardrails**: constraints that protect security, quality, cost, and accountability.
- **Reference material**: customer work that demonstrates the theme in practice.
