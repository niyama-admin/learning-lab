# Devtools

Small, self-contained tools for working with agents and infrastructure day to day. Each tool lives in its own folder with a README covering install, configuration and known limits, and keeps no private paths or workload names in the code.

| Tool | Purpose |
|---|---|
| [tmux workspace](tmux-workspace/README.md) | One-command tmux layout for supervising many Claude Code sessions: Kubernetes watch panes, the agent view, and five session panes ranked by recent activity then status |
